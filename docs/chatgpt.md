我的想法：

**定位：AI 数学教师工作台（类似 Cursor，但服务教师）**

核心不是聊天，而是 Harness + Agent。

### 1. 备课 Agent（核心）
教师选择章节/上传教材：

输出：
- 教学目标
- 知识结构图
- 重难点分析
- 教案
- 例题设计
- 分层练习
- PPT大纲

### 2. 试题 Agent
上传试卷/作业：

自动：
- OCR识别
- 公式解析
- 知识点标注
- 难度分析
- 错因分析
- 生成变式题


### 3. 班级学情 Agent
长期记录：

- 每个班薄弱点
- 每个学生错题规律
- 知识掌握情况

教师问：

> 为什么小明最近函数题总错？

AI直接分析。


### 4. 日常教学 Agent
课堂辅助：

- 快速生成解释
- 生成板书
- 设计互动问题
- 根据学生水平调整讲解


### 5. 客户端形态
参考 Cursor：

左侧：
- 教材
- 知识库
- 班级数据

中间：
- AI协作区

右侧：
- 教案
- PPT
- 习题
- 分析报告


### 最小 MVP：
先做：

**“教师上传教材 + AI生成备课资料 + 作业分析”**

不要先做学生端。

核心竞争力：

不是模型，而是：
**教材知识库 + 教师工作流 + 学生长期数据记忆。**

本质上做一个“数学教师版 Cursor”。
