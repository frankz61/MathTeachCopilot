# eval —— 评测集（还没建）

docs/claude.md 第六节：这是**唯一能证明「比通用大模型强」的东西**。

## 要什么

≥100 道人工标注题，持续测两个指标：

1. **生成题的答案正确率** —— 验算器说 green 的题，人工复核是不是真的对
2. **难度标注准确率** —— 标成 A/B/C 的题，教师是否认同

## 为什么现在还是空的

标注需要一位真实教师投入时间。这是资源问题，不是技术问题。
在有人认领之前，先不要假装有 eval——没有 eval 集，
「我们的题比 ChatGPT 准」就只是一句话。

## 建议的最小起步

先从 spike 和真实使用中攒 30 道，覆盖第 21 章的四种解法
（配方法 / 公式法 / 因式分解法 / 根与系数关系），每种至少含两道故意做错的，
用来测验算器的拦截率——**反例比正例重要**。
